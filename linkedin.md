Few weeks back. 11pm. Random Friday.

Solving a LeetCode problem in VS Code. Switching to the browser for the statement, switching back to write code, copy-pasting examples one by one to test, switching again to read the next hint. Somewhere around the 6th alt-tab, a thought hit me:

"Can we make this less annoying? Yes we can."

No plan. No roadmap. Opened a new folder, started typing.

A few late nights later, I shipped it to the VS Code Marketplace. Called it lcex.

The funny part: it started as a tiny "open the problem inside VS Code" hack and slowly kept growing. Every time I hit a small annoyance while solving questions, I added a feature for it. Two and a half months later, it's much bigger than I planned.

Where it stands today:

- 5,000+ downloads across VS Code Marketplace and Open VSX
- 4.45 / 5 rating
- 26 features shipped, 60+ commits
- Real users actually using it daily, including me

In the grand scheme, this isn't a "viral side project" or a Show HN front page story. And honestly, that's the point of this post.

For the longest time I used to wait for the "big" win before letting myself feel good about anything. The funding. The 100k stars. The huge launch. Meanwhile a hundred small wins quietly walked past me without a high-five.

5,000 downloads is small. But it's 5,000 strangers who clicked install on something that didn't exist before I sat down on a random Friday night. Someone, somewhere, is solving a Two Pointers problem right now with my little extension open. That's wild if you stop and actually let it land.

So a small reminder, mostly to myself:

Ship the random Friday idea. Don't wait for the big number to feel proud. Celebrate the tiniest wins, the first install, the first 5 star review, the first "hey, this is cool" DM. They're not consolation prizes for the bigger thing you're chasing. They are the thing.

P.S. for the curious, here's roughly what it does now (started as a problem opener, ended up here):

- Mock interview mode with timed sessions, focus layout that hides hints, and a per-attempt report you can review later
- Company-wise problem browser. 463 companies, with frequency and acceptance rate, so prepping for a specific one is a single click
- Inline feedback on save. Actual vs expected values rendered as ghost text next to the line, no popups, no separate panel
- A hint agent that reads your code (complexity, hotspot, input size) and gives a nudge based on what you actually wrote, not a generic tip
- The usual: XP, streaks, study plans, multi-language templates, cloud sync

It's on the VS Code Marketplace (search "LeetCode Practice" by nikkyamresh) and Open VSX: https://open-vsx.org/extension/nikkyamresh/leetcode-practice

Feedback, ideas, brutal critique, all welcome.

Now back to alt-tabbing... wait, I don't have to anymore.
